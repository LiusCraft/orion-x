# 产品功能

Orion-X 从音频采集到语音合成全链路自研可控，提供企业级实时语音 AI 能力。

## 实时语音识别 (ASR)

基于 Silero VAD + 阿里云 DashScope 实时语音识别引擎，支持：

- **语音活动检测 (VAD)** — 自动检测说话起止，支持静音超时自动断句
- **实时转写** — 流式 ASR，边说话边出字，延迟 <500ms
- **多语言支持** — 中英文混合识别
- **可选的 VAD 模式** — Silero VAD（默认）或旁路模式

## 自然语音合成 (TTS)

异步管道架构，多音色可选：

- **异步 TTS Pipeline** — 句间零等待，Agent 输出流式驱动 TTS 合成
- **多音色** — 阿里云 CosyVoice 系列，支持男声/女声/童声等
- **16kHz 输出** — Opus 编码，适合网络传输
- **文本分段** — 智能长句切分，降低首字延迟

## 多模型 LLM Agent

OpenAI 兼容接口，灵活接入：

- **多 Provider** — 支持 OpenAI API、智谱 GLM-4 等兼容服务
- **流式输出** — SSE 流式 Agent 推理，边推理边合成
- **工具调用** — 完整的 function calling 循环，支持多工具并发
- **上下文管理** — Session 级对话轮次追踪

## MCP 工具生态

通过 Model Context Protocol 标准协议扩展能力：

- **多传输方式** — stdio / SSE / Streamable HTTP
- **热加载** — 运行时注册/注销 MCP 服务器
- **工具注册** — 自动发现 MCP Server 的工具列表
- **权限管理** — 工具级别的访问控制

## 智能会话记忆

层级记忆系统，适应不同场景：

- **Session Buffer** — 对话轮次级短期记忆
- **Long-term Memory** — SQLite 持久化长期记忆，跨会话回溯
- **RRF 重排序** — 记忆检索 + 多路召回融合
- **向量化存储** — 语义搜索增强

## 管理控制台

一站式 Web 管理平台：

- **Agent 管理** — 创建、配置、监控语音 Agent
- **MCP 市场** — 浏览和安装社区 MCP 工具
- **模型监控** — 多 Provider 用量与延迟追踪
- **语音管理** — 音色广场与语音克隆
- **计费与额度** — API 调用统计与额度管理
