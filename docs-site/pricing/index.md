# 定价

Orion-X 核心框架完全开源，企业版提供额外的部署支持和管理功能。

## 开源版

| 项目                            | 说明               |
|---------------------------------|--------------------|
| 价格                            | **免费**           |
| 许可                            | MIT License        |
| 范围                            | 全部核心引擎、管道框架、CLI VoiceBot |
| 支持                            | GitHub Issues 社区支持 |

**包含：**

- ASR / TTS / LLM 全链路管道
- 多 Provider 支持（阿里云 Dashscope / OpenAI 兼容）
- MCP 工具扩展
- Session 与记忆系统
- CLI VoiceBot 示例应用

## 企业版

| 项目 | 说明 |
|------|------|
