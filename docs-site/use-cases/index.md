# 应用场景

Orion-X 灵活的管道架构使其能够适应多种实时语音交互场景。

## 智能客服

构建语音交互客服系统，降低人工坐席压力。

- **自动应答** — 基于 LLM Agent 理解用户意图，自动回答常见问题
- **平滑转接** — 人工介入时携带完整对话上下文，无需用户重复描述
- **多轮对话** — 结合记忆系统，支持复杂业务场景的多轮交互
- **7×24 在线** — 无需排班，随时响应

**典型架构：**

```text
用户通话 → ASR → Agent (LLM + 知识库) → TTS → 语音回复
                                    ↓
                             人工坐席 (兜底)
```

## 语音助手 / 智能硬件

为智能音箱、车载系统、嵌入式设备提供实时语音交互能力。

- **低资源占用** — Go 运行时高效，适合资源受限设备
- **自定义唤醒** — 支持结合前端唤醒词引擎
- **技能扩展** — 通过 MCP 协议接入自定义技能（查天气、控制设备等）
- **可离线部署** — 核心框架自包含，按需接入云端 ASR/TTS

## 会议转写与摘要

实时会议语音转文字 + 智能总结。

- **实时转写** — 多说话人场景下实时输出文字
- **智能摘要** — 结合 LLM 自动生成会议纪要和待办事项
- **历史检索** — 长期记忆系统支持回溯历史会议内容
